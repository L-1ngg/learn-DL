前期基础操作说明参数与损失速查

Demo 1：从散点中学出一条直线

这次把参数、损失与训练放进一个完整实验。目标：跑出图，再改一个条件解释变化。

uv run demos/01-noisy-line/main.py

模型是 预测 = x*w+b。w 控制斜率，b 控制上下平移。数据按 目标 = 2*x+1+随机噪声 生成。

只读核心训练循环

prediction = x * w + b
loss = ((prediction - y) ** 2).mean()
optimizer.zero_grad()
loss.backward()
optimizer.step()

x 和 y 是装有一批数字的 tensor，可以先当作能够整体计算的数组。前两行同时计算这一批例子的预测与均方误差。后三行依次清空旧梯度、自动计算梯度、更新参数。来源：PyTorch 官方训练教程。

从图里读出三个现象

180 个点参与训练，另 60 个测试点只在训练后核对。拟合线不会穿过每个点，因为观测带有噪声。相同数据和初始参数下，改变学习率会显著改变训练结果。

本次基准：学习率 0.05，训练 MSE 约 0.137，测试 MSE 约 0.156。这只反映当前人工数据集，不代表真实任务的可靠性。测试集不用于选择设置，实际调参还需验证集。

轮到你改变一个条件

把生成噪声的幅度从 0.4 改为 0.0。先猜：点会如何分布？参数应接近多少？损失会不会更低？然后运行，看结果是否符合预期。

运行后再核对

点会落在 y=2x+1 上；合适的学习率下，w 和 b 会接近 2 和 1，损失可降得很低。学习率过大的实验仍可能失败，去掉噪声没有修复过大的更新步长。
