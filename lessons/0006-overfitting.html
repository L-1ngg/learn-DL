Demo 3：训练得更好，预测却更差？

只用 80 个训练点，并故意标错其中 12 个。比较两个隐藏宽度不同的网络。验证集和测试集标签保持正确。

uv run demos/03-overfitting/main.py

观察模型在迎合什么

大网络训练损失约 0.0003，却有约 1.266 的验证损失；较早检查点的验证损失约为 0.353。随着训练继续，它越来越适应训练例子里的细节，包括错误标签。由于训练标签含噪声而验证标签干净，不能只看两种损失的绝对差距；更关键的是观察随时间的变化。

灰虚线是原来的圆，点的颜色是训练标签，黑圈标记被翻转的标签。观察继续训练后的区域是否绕着错标点弯曲。

用验证集决定何时停

每 10 次更新检查一次，验证损失改善就保存参数；连续 40 次检查不改善则冻结选择。两个网络分别选择检查点，再按验证损失选网络。测试集只在选择结束后评估最终模型。本次选中的小网络测试准确率为 83.2%。

保存参数必须保存独立快照，不能让它随后续训练一起改变。参阅PyTorch 保存模型说明。

改变一个条件

uv run demos/03-overfitting/main.py --flip-count 0

去掉错误标签，保持其他条件相同。新结果在 flips-0 文件夹，不覆盖原图。你预计验证曲线和边界会怎样变化？运行后把观察发回对话。

观察提示

没有错误标签时，模型不需要为了迎合错标而扭曲边界。但样本仍少，模型与优化限制仍在，不保证验证损失始终下降，也不保证测试完全正确。
