第三课 · 从手动尝试到程序尝试

让程序尝试参数

沿用刚才的例子：输入为 3，目标为 6，预测等于输入乘以 w。损失取预测与目标之差的绝对值。今天只把手动尝试交给程序。

先定一个起点，再逐个尝试

先保存 w = 0 的结果。程序接着尝试 1、2、3，每次都计算预测和损失；只有新损失更小时，才替换保存的最佳参数。

x = 3
target = 6

best_w = 0
best_loss = abs(x * best_w - target)

for w in [1, 2, 3]:
    prediction = x * w
    loss = abs(prediction - target)
    print("w =", w, "prediction =", prediction, "loss =", loss)

    if loss < best_loss:
        best_w = w
        best_loss = loss

print("best_w =", best_w, "best_loss =", best_loss)

[1, 2, 3] 是候选数的列表；for 让 w 依次取这些值；if 表示条件成立时才执行缩进的代码。best_w 保存截至目前最好的参数，不会因为后来试了更差的参数就丢失。

运行文件：0001-try-parameters.py。在仓库根目录执行：

uv run exercises/0001-try-parameters.py
核对结果

候选 w = 1、2、3 的损失依次是 3、0、3。最后保存 best_w = 2、best_loss = 0。虽然循环最后尝试的是 3，保存的最佳参数仍然是 2。

只在尝试过的值中找最好

这是教学用的有限枚举，不是梯度下降。它自动寻找较低损失的参数，但只考察起点和列出的候选值。参数很多时，逐个组合尝试会很昂贵；后面再学习更有效的更新方法。参数与损失的关系见《动手学深度学习》3.1.1.2，教材用平方损失，本例沿用绝对误差。

改一个数，先猜再运行

保持候选值不变，把 target 从 6 改成 7。程序会保留哪个 w？最小损失是多少？

核对思路

初始 w = 0 的损失为 7；候选 1、2、3 的损失分别为 4、1、2，所以保留 w = 2，损失为 1。这不代表所有可能的 w 中没有更好的值，只代表本次尝试过的值中它最好。
