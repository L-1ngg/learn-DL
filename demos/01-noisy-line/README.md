# Demo 1：拟合带噪声的直线

在仓库根目录运行：

```bash
uv run demos/01-noisy-line/main.py
```

打开 `outputs/results.png` 看图，`outputs/metrics.json` 保存数值。数据在本地生成，共 240 个例子；CPU 运行，不下载数据集。

## 先看结果，再读代码

左图比较数据点、真实无噪声关系和学到的直线。右图只改变学习率，比较 100 次更新内的训练损失，纵轴是对数刻度。

- `0.001`：在相同更新次数内进展慢。
- `0.05`：本例适用的学习率，拟合到接近真实关系。
- `1.0`：本例步子过大，误差增长。这不是建议使用的学习率。

## 四个新概念

1. **偏置 b**：模型从 `x*w` 变为 `x*w+b`。w 控制斜率，b 控制上下平移；两者都从数据中学习。
2. **噪声**：真实关系是 `2*x+1`，但观测值加入随机扰动。因此一条直线不必穿过每个点，训练损失也不必为零。
3. **自动求导**：`loss.backward()` 自动计算两个参数的梯度；`optimizer.step()` 更新参数。`zero_grad()` 清掉上一轮留下的梯度。
4. **训练与测试分离**：180 个样本参与更新，另 60 个只用于观察训练后表现。计算测试损失仍需要测试标签，但预测本身不需要标签。

本例固定种子和样本顺序；三个实验共用同一训练集与测试集。测试集用于教学展示，不依据它选择学习率或模型；实际调参应另外使用验证集。这里只说明同一种人工数据分布上的表现，不证明真实任务中可靠。

## 只改一个条件做实验

先完成一次原始运行，再把噪声幅度 `0.4` 改为 `0.0`。运行前猜测：学到的 w、b 会更接近多少？损失还能否降得更低？再次运行会覆盖 outputs 中的上次结果，比较前先记下基准数值。

读代码顺序：先看 `main()` 的数据生成，再看 `train()` 的训练循环，最后看测试损失。绘图代码可以暂时跳过。有疑问直接回到对话，不必逐行啃完。
