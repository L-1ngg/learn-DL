# Demo 4：看见注意力如何混合信息

```bash
uv run demos/04-attention/main.py
```

不训练，不下载数据，CPU 上计算三个位置、每个位置两个数。打开 `outputs/weights.png` 看权重，终端和 `outputs/results.json` 给出输出。A/B/C 是位置名，不是真实词；数值人工指定，不能解读为模型理解了语言。

## 从已有知识出发

之前 Linear 对每个点独立计算。注意力允许一个位置读取其他位置的信息，并按当前输入计算读取比例。本例同一批 X 生成 Q、K、V，因此是单头自注意力；它只是 Transformer 的一个部件，不是完整 Transformer。

```python
x = [[1, 0], [0, 1], [1, 1]]
q = x @ wq
k = x @ wk
v = x @ wv
```

`@` 是矩阵乘法。本例 wq、wk 为单位矩阵，故 Q=K=X；wv 把第一维放大 10 倍、第二维放大 20 倍，因此 V 为 [[10,0],[0,20],[10,20]]。真实网络会学习投影参数；此处固定它们以便手算。Q/K 的作用是计算匹配分数，V 是真正按比例混合的内容，不要把这三种角色当成模型必然理解的语言含义。

## 核心三步

```python
scores = q @ k.T / math.sqrt(q.shape[-1])
weights = torch.softmax(scores, dim=-1)
output = weights @ v
```

1. Q 每一行分别与 K 每一行做点积：对应数字相乘后求和。第一行 [1,0] 对 A/B/C 得到 [1,0,1]，除以 sqrt(2) 后约为 [0.707,0,0.707]。缩放是标准 scaled dot-product attention 的一部分。
2. softmax 将每个分数取指数，再除以本行指数之和，得到正权重，各行加起来为 1。第一行约 [0.401,0.198,0.401]。它是读取比例，不是分类准确率或因果解释。
3. 按这些比例混合 V。第一行输出约 [8.022,11.978]，不是挑一个位置复制，而是做加权求和。

形状：[3,2] @ [2,3] → [3,3] 分数/权重；再 @ [3,2] → [3,2] 输出。行代表谁正在读取，列代表读取谁。

## 因果遮罩

序列顺序为 A、B、C。因果模式下，A 只能读取 A；B 能读取 A/B；C 能读取 A/B/C。程序在 softmax 之前把未来位置分数设为负无穷，所以对应权重为 0。

因此 A 的权重变为 [1,0,0]，输出就是 V_A=[10,0]。遮罩不禁止关注自己。在自回归文本生成中，这用于避免当前位置看到未来内容；本例没有位置编码或文本训练。

## 动手改一个值

把 wv 第一行中的 10 改成 30，其他不变，先猜权重图和最终输出哪个会变化。注意输出文件会覆盖上次结果。

核对：Q、K 不变，权重不变；V 改变，混合后的输出改变。这个对照帮助区分“读取多少”和“读取的内容”。把观察或不懂的计算发回对话。
